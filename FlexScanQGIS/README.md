# G-CHAM Flexible Scan for QGIS (試作 v0.1.16)

QGIS 3.28以降で動作する、ポリゴン集計データ用の試作プラグインです。RやSaTScanは不要です。

## 現在の機能

- ポリゴンレイヤ、地域ID、症例数、期待数を指定
- リスク人口から期待数を自動計算（期待数フィールドの直接指定も選択可能）
- ポリゴン境界の接触からQueen隣接を作成（辺または点で接触）
- 各起点地域について、最大K地域に含まれる最近隣地域を重心距離から選び、その範囲内で起点を含む連結集合を探索
- 重心座標は任意のX・Yフィールドを指定可能。未指定の場合はポリゴンの幾何学的重心
- Poisson尤度比によるホットスポット／コールドスポット候補の評価
- 条件付き多項分布によるモンテカルロp値
- 一次クラスターに加え、互いに重ならない二次クラスターを逐次探索
- 二次クラスターを一次クラスターと同じモンテカルロ最大統計量分布で個別検定
- 全地域・検出クラスター・有意クラスターのみの空間レイヤをGeoPackageに保存し、クラスター順位ごとにカテゴリ色分け
- 全検出クラスターの統計サマリーを別ファイルのExcel（クラスター一覧、解析設定の2シート）に保存
- 入力確認・隣接行列作成・候補探索・モンテカルロ検定・保存の進捗ウィンドウとログファイル
- 解析設定画面で結果GeoPackageの保存先と候補領域数の上限を指定
- 候補領域を固定幅配列に格納し、候補重複を抑制して、観測統計量とモンテカルロ評価をNumPyで小分けに処理
- 既定の候補上限は200万件。設定画面で最大1,000万件まで指定可能だが、メモリ保護のためKに応じて実際の上限が低くなる場合がある
- 有意水準α（既定0.05）以下のクラスターのみを`significant_clusters`レイヤとして保存し、QGISプロジェクトに追加
- 統計テーブルはGeoPackageレイヤにせず、`*_cluster_summary.xlsx`として別途保存
- 保存したGeoPackageをQGISプロジェクトへ追加
- Flexible Scanを表すアイコンをプラグインメニューとQGISツールバーに表示
- 有意水準（既定0.05）以下のクラスターのみを独立レイヤに保存し、全クラスター統計はExcelへ出力

## 重要な制約

この版はTango & Takahashi (2005) の「起点＋重心距離が近い最大K地域の範囲で、起点を含む連結候補を探索する」定義と、Otani & Takahashi (2021) が説明する二次クラスター手順に近づけています。ただしPythonによる独立実装であり、FleXScanまたは`rflexscan`との数値同等性は未検証です。原著で使われた人口重心、隣接関係の作成方法、同順位時の扱い、対数尤度比、乱数生成器、二次クラスター結果を同一データで照合していないため、研究の確定結果として使う前に照合が必要です。

起点ごとに候補領域を列挙するため、地域数や最大クラスターサイズ、隣接構造によって候補数と処理時間が急増します。候補領域の既定上限は200万件で、設定画面から上限を変更できます。Kに応じたメモリ保護値を超える上限は自動的に調整され、実際に適用した上限はログと出力属性`fs_candidate_limit`に記録します。上限到達時は解析を中止し、結果ファイルは作成しません。大規模データでも無制限に実行できるわけではなく、対象範囲、K、候補数、シミュレーション回数の組合せにより処理時間が長くなるため、まず少ないシミュレーション回数で計算量を確認してください。現在の隣接定義はQueen contiguityです。隣接行列は解析時にメモリ上で作成し、対称二値行列（対角0）として扱います。

出力属性の`fs_cluster_rank`はクラスター順位（1=最尤、2以降=二次）で、各クラスターを識別するための値です。`fs_cluster_n`はそのクラスターに含まれる地域数であり、検出クラスター総数ではありません。全検出クラスターの統計はGeoPackageと同じ保存先に作成する`*_cluster_summary.xlsx`で確認できます。有意クラスターは、設定した有意水準α以下のMonte Carlo p値を持つクラスターです。有意クラスターは設定した有意水準α以下のMonte Carlo p値を持つクラスターです。地図のシンボルは順位をカテゴリとして扱い、クラスターごとに色分けします。二次クラスターは先に選択されたクラスターと地域が重ならない候補から、LLRの高い順に選びます。「二次クラスター数」の0は`rflexscan`の既定動作に合わせ、p値が1に達するまで探索します。正の値は二次クラスターの最大出力数です。各二次クラスターのp値は、各シミュレーションにおける全候補の最大統計量分布に照らして個別に算出します。シミュレーション回数を0にした場合はp値が得られないため、自動探索では一次クラスターだけを出力します。自動期待数は「全症例数×各地域のリスク人口÷全地域のリスク人口合計」で計算し、地域間で発生率が等しい帰無仮説を置きます。年齢標準化など層別調整をした期待数が必要な場合は、別途計算済みの期待数フィールドを指定してください。この試作はBernoulliモデル、共変量調整、時間解析、FleXScanの`RESTRICTED`統計量には未対応です。

## インストール

1. QGISで「プラグイン」→「プラグインの管理とインストール」→「ZIPからインストール」を開きます。
2. このZIPを選択し、インストールします。
3. 「プラグイン」メニュー直下の「G-CHAM Flexible Scan」を実行します（サブメニューは作成しません）。

## 研究利用前の照合事項

- `rflexscan`の公開サンプルデータを用いて入力・隣接関係・候補集合・統計量・p値を比較する。
- `rflexscan` 1.2.0の`FLEXIBLE`、`ORIGINAL`、`MULTINOMIAL`設定を基準にする。
- 同じ地域順、期待数、隣接行列、最大クラスターサイズ、モンテカルロ回数、乱数条件を揃える。
- 乱数生成器が異なるため、同じ乱数種だけではシミュレーション列の一致を保証しない。観測統計量、シミュレーション分布、p値を分けて評価する。
- 同一データで候補集合の完全一致、最大対数尤度比、クラスター構成、Monte Carlo p値を評価し、相違を記録する。
- 実データ規模ごとに候補数、計算時間、ピークメモリを記録し、設定した候補上限内で完了する範囲を確認する。
